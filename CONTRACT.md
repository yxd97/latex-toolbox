# Browser prototype module contract

Buildless classic scripts, ordered core.js, table-editor.js, figure-editor.js, app.js. No CDN/network/runtime dependencies. Must work from file:// and HTTP. Chinese UI. Expose window.ToolboxCore / window.TableEditor / window.FigureEditor. Each editor exports mount(host, data, onChange) returning { destroy(), refresh(data) }; refresh may rebuild. onChange(newData) informs the app, which DOES NOT remount editor on every change. Module owns its working data reference and renders internally as needed. Use DOM/textContent or escaped HTML for user content. Editors must clean up global listeners on destroy.

Project: {version:1,name,active:'table'|'figure',table,figure}.

Core exports: createProject(), escapeLatex(text), parseCSV(text,delimiter=','), importCSV(text), exportTable(table), exportFigure(figure), exportProject(project,kind), normalizeProject(value), figureBudget(row,gap). Exports return {code:string,packages:string[],warnings:string[]}; code is full float snippet, packages contains complete \usepackage lines. importCSV returns table data. normalizeProject validates untrusted JSON and returns safe canonical Project, throws on invalid unsupported input. figureBudget returns {total:number,remaining:number,overflow:boolean} (sum item widths plus gap*(n-1)). No image decoding needed in core.

table: {rows:5,cols:4,cells:Cell[][],merges:Merge[],colWidths:number[],mode:'tabularx'|'tabular',borderPreset:'booktabs'|'grid'|'none'|'custom',caption:string,label:string,captionStyle:Style,span:'single'|'double',width:number}. Cell={text:string,style:Style,borders:{top:boolean,right:boolean,bottom:boolean,left:boolean}}. Style={bold:boolean,italic:boolean,align:'left'|'center'|'right',valign:'top'|'middle'|'bottom',fg:'#1f2937',bg:'#ffffff',size:'footnotesize'|'small'|'normalsize'|'large'}. Merge={r:number,c:number,rs:number,cs:number}. Covered cells retain content but export/render skips them. colWidths sums to 1. width is .2..1 of float linewidth. borderPreset custom uses cell borders; booktabs top/mid after first row/bottom, no vertical rules; grid uses every border; none no borders. User border edit switches custom. Font and rule widths may use native units; layout widths must be relative linewidth. No vertical spacing UI or exported vspace or row-height settings. CaptionStyle uses bold/italic/align/fg/size; defaults fine.

figure: {rows:[{id:string,items:Image[]}],caption:string,label:string,captionStyle:Style,span:'single'|'double',width:number,gap:number,align:'top'|'bottom'}. Image={id:string,name:string,src:string,width:number,caption:string,label:string,style:Style}. src is local data URL, name filename only used in LaTeX. 1..3 items per row, width fractions relative to figure content container; gap default .02, widths auto normalized when adding/removing. Each row fits sum widths+(n-1)*gap<=1. Empty row allowed in editor but warn/skip on export. Native images PNG JPEG SVG and PDF (placeholder for PDF) accepted; unsupported extension rejected. SVG uses includesvg, others includegraphics; preserve filename including extension. Images keep aspect ratio. Per-image caption and global caption are editable directly in preview. Reorder/move images across rows via drag/drop and accessible buttons; widths adjustable. No free Y positioning.

Core export table uses table/table* outer float, caption/label outside adjustbox, adjustbox max width=<width>\linewidth, tabular or tabularx. Need relative column widths accounting for tabcolsep/rules. Figure uses figure/figure*, content minipage of width*linewidth, subfigure per image (subcaption) widths relative current linewidth; includegraphics/includesvg width=\linewidth inside subfigure. Explicit relative hspace, suppress accidental source spaces via %. No vspace; normal row paragraphs allowed. Escape ordinary text everywhere; no formulas/raw LaTeX required. Safe labels (normalize invalid chars), paths filename only with safe escaping/reliable handling. Core warns about SVG compilation dependency and browser approximation; packages deduplicated. UI must display warnings where useful.

App shell owns project save/restore, undo/redo snapshots, import/export JSON, export tex, copy, package list and active tab, global document width/span/caption label controls can be in editors. Editors call onChange for every committed edit. app attaches editor to #editor-host, displays code #latex-code and #package-code. Shared CSS handled by root, use descriptive classes and standard buttons/inputs/labels. Each editor can include section panels, a .editor-toolbar, .paper-preview, .field, .field-row, .section-label, .muted, .icon-button, .primary/.secondary/.danger classes.
